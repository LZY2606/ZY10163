# 视界标定室

可重放的射电干涉标定室: 研究者可在同一页面检查原始可见度、手工旗标、
自动建议与求得的天线增益, 并严格重放历史求解运行。

## 安装与运行

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q && .venv/bin/uvicorn app:app --host 127.0.0.1 --port 5503
```

访问 http://127.0.0.1:5503 即可看到“视界标定室”操作页面。

## 数据口径

- **可见度样本**: `(ant1, ant2, time, channel) -> V = re + i·im`, 附带整数质量位
  (`quality & 1` 表示坏样本)。约定 `V_ij = g_i · conj(g_j) · M_ij`, 模型 `M_ij = 1` (点源)。
- **规范化**: 导入时统一为 `ant1 < ant2` (交换则取共轭), 并按
  `(ant1, ant2, time, channel)` 排序后取 SHA-256 作为数据集哈希——
  **基线导入顺序不影响数据集身份**, 相同内容去重。
- **旗标**: 只增不改的区间记录 `(scope, ant1, ant2, t0..t1, c0..c1)`,
  每条携带来源 (`ingest` 质量位 / `manual` 手工 / `auto` 自动建议) 与理由;
  同一样本被多个区间覆盖时全部保留。被旗标样本**不进入求解方程**,
  但仍出现在残差与图形输出中 (可定位)。
- **求解**: 按 `(时间窗 time_bin, 频率分组 chan_group)` 分箱, 箱内复数向量平均
  (对跨 ±π 绕回安全), 再解对数幅度 / 相位最小二乘 (岭正则化 + 参考天线相位、
  平均幅度规范)。输出每组复增益、可求子图、未定标天线与条件数诊断。
- **失败语义**: 参考天线无可用数据、基线图不连通或正则化方程退化
  (条件数超阈) 时**绝不返回全零增益**, 运行状态为 `failed`/`degraded`,
  并给出可求子图、未定标天线与数值条件诊断。
- **相位显示**: 沿频道轴 `numpy.unwrap` 解缠, 正确跨过负实轴 (±π) 分支。

## 固定夹具

四天线 (A1–A4) × 4 时段 × 8 频道, 内含:

- A1/A2/A3 闭合三角形 (点源模型下闭相位 ≈ 0);
- A4 全程质量位坏 (完全被旗标的参考天线候选);
- A3 相位随频道线性变化并跨过 ±π (跨频道相位绕回);
- A2 在 t≥2 有 +0.5 rad 相位突跳 (手工旗标对象);
- 基线 A2–A3 在 t=1、频道 4–6 有局部干扰 (自动建议对象)。

`POST /api/datasets/import-fixture?order_seed=N` 可以不同基线顺序导入,
哈希与求解结果不变。

## 重放与导出

- 每次求解运行固定 `dataset_id + 参数 + 旗标 id 集合` 快照;
  之后新增旗标**不会**改写旧结果。`POST /api/runs/{id}/replay`
  用原快照重算并比对结果哈希。
- `GET /api/runs/{id}/export` 导出完整运行记录 (数据 + 旗标 + 参数 + 结果哈希);
  `POST /api/runs/import` 在清空后的数据库中重建数据、重放求解并校验哈希一致
  (页面上的“清库重放复核”按钮即执行此流程)。

## 主要 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/datasets/import-fixture` | 导入固定夹具 (可乱序) |
| GET | `/api/datasets/{id}/visibilities` | 样本 + 命中旗标 + 来源 |
| POST | `/api/flags` | 添加手工旗标区间 |
| POST | `/api/flags/suggest` | 自动建议 (可选落库) |
| POST | `/api/runs` | 求解 (快照当前旗标集) |
| POST | `/api/runs/{id}/replay` | 重放旧运行 |
| GET/POST | `/api/runs/{id}/export`, `/api/runs/import` | 导出 / 清库重放 |

## 测试

`pytest` 覆盖: 导入顺序无关性、全旗标参考天线、断图子图一致性、
退化方程不伪造增益、旗标不进入方程但可定位、自动建议命中干扰、
跨负实轴相位解缠、闭相位、旧运行不被新旗标污染、清库重放校验。
